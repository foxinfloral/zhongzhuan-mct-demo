POST /v1/mct/estimate · 估算 Estimate

别名 alias：POST /v0/mct/estimate。契约 contract：io_v0.2。

请求字段 Request fields（下表照录仓库 README）：取值以 mct_service/normalize.py 为准，严格匹配，不接受别名。字段缺省（缺失 / null / 空串）时使用默认值，HTTP 仍为 200，并在 flags.defaults_applied 列出字段名、flags.labels 追加「已用默认 字段=值」。

字段 Field允许值 Values默认 Default
flowE-C / E-D（业务含义【未确认】）E-D
nation国内 / 外籍外籍
stand近机位 / 远机位 / 远远机位远机位
period早 / 中 / 晚 / 凌晨中
through是 / 否否
carry_on_only是 / 否否
ac_type窄体 / 宽体窄体
seat_zone前舱 / 中舱 / 后舱后舱
window_min数字，> 055
modeexcel_default / hybrid_t3hybrid_t3
request_id可选字符串，原样回显；缺省时返回 null；不校验唯一性—

其它取值返回 HTTP 400。废弃键：through_check→through、hand_baggage_free→carry_on_only、aircraft→ac_type 目前仍会被映射（并带 flags.deprecated_keys_used 与【废弃】标签），新接入请勿使用；passenger_type 不做映射：未同时提供 nation+seat_zone 时返回 400，同时提供时被忽略。

响应 Response（顶层键见 mct_service/engine.py）：request_id, contract_version, engine_version, mode, inputs, summary, compare{excel_default, hybrid_t3}, nodes[], flags, engine

块 Block内容 Contents（io_v0.2 §2）
summaryp50_min（Σ 计入 P50）、p90_min（P50 + √Σ(P90−P50)²，不是 ΣP90）、p95_min（P50 + 1.2852×√Σ(P90−P50)²；系数来源【未确认】）、window_min、risk_level（低风险|可控风险|高风险|极高风险）、action、included_count、e28（Σ(P90−P50)²）
nodes[]id ∈ taxi_in, deplane, bus, imm, customs, baggage, id_process, walk, apm, security；字段 name, included, p50_min, p90_min, source, source_n, note
flags布尔位（如 flow_ec_ed_meaning_unconfirmed、window_clock_unconfirmed、degrade_flow_unconfirmed、baggage_in_engine_scope_unconfirmed、period_bins_unconfirmed、walk_path_unconfirmed、missing_nodes 等）+ labels：字符串数组（中文提示，含【未确认】/【缺项】）

风险档 Risk tier：window ≥ P95 低风险；≥ P90 可控风险；≥ P50 高风险；否则极高风险。默认场景 hybrid_t3：74.4 / 94.22 / 99.87，极高风险。

错误 Errors：HTTP 400 {"error": "...", "flags": {"labels": [...]}}。

注：min-loop 页的决策层（success_prob、ladder、recommended_action_id）为前端演示计算，不在 estimate 响应中。

POST /v1/mct/feedback · 回灌 Feedback

别名 alias：POST /v0/mct/feedback。演示：只落盘（容器临时目录，重启清空），不改引擎、不派单。

字段 Field必填 Req.说明 Notes
request_id是关联 estimate；缺失 → 400 + 【缺项】request_id
recorded_at否缺则服务端填接收时刻（ISO8601）
outcome.made_connection推荐true/false；缺失或未知 → null + flag outcome_unknown，仍接收
outcome.outcome_note否短注，不含个人信息
actions_taken[]否{code, label, at}；code ∈ observe, warn_pool, inflight_warn, pre_rebook, rush_transfer, dedicated_assist, other；未知 code → flag action_code_unconfirmed
timestamps.*否in_ata, out_atd_or_gate_close, connection_declared_at；缺项逐项标【缺项】
pax_key否脱敏键，须匹配 ^[A-Za-z0-9._:-]{1,64}$；禁止证件号/手机/姓名
estimate_echo否当时 summary 摘要（mode, window_min, risk_level, p50/p90/p95）；缺则【缺项】estimate_echo
source否默认 occ_demo_ui
operator_note否短文本，服务端截断

响应 Response：{"ok", "feedback_id", "request_id", "recorded_at", "path", "flags": {"labels", …}}。flags.labels 固定返回；outcome_unknown、action_code_unconfirmed、pii_stripped、pii_keys_stripped 仅在触发时出现。依据为后端 mct_service/feedback.py（指纹 4752cfeb7835）；线上是否在跑这份代码【未确认】。落盘记录含 schema_version, received_at, engine_version, contract_version, payload, flags。

另有 GET /v1/mct/feedback/export?date=YYYY-MM-DD（NDJSON；缺 date → 400【缺项】date）。
